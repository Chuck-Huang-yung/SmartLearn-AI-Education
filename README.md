# SmartLearn 智慧學習輔助平台 🎓

本專案為一款結合 AI 技術與視覺化管理的適性化學習平台，旨在降低學生的認知負荷，並提供個人化的學習體驗。

## 🛠️ 技術架構
* **前端框架：** React, TypeScript
* **UI/UX 實作：** Tailwind CSS (響應式組件化開發)
* **後端與 AI 串接：** Node.js, Google Gemini API

## ✨ 系統核心亮點
* **AI 適性化學習 (Gemini API)：** 根據每日達標狀況與弱點，自動生成專屬學習策略與重點複習提醒。
* **視覺化排程儀表板：** 將繁雜課程轉化為直覺的「甘特圖」與「整合行事曆」，一目了然每日進度。
* **一站式學習導覽：** 整合不同科目筆記、講義與測驗，並具備好友社群共學機制。
* **數據驅動擴充性：** 架構預留「教師端」接口，支援未來教與學的雙向數據回饋。
